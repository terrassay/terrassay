# Trademark Policy

## Project marks

The project name, logo, and wordmark (the "Terrassay marks") identify the project and its official releases. The Apache-2.0 licence does not grant permission to use the marks.

## Permitted use

You may:

- Refer to the project by name in articles, talks, courses, and comparisons.
- State that your product "integrates with" or "is built on" Terrassay, if true.
- Use the name in a repository/package description that is clearly about the project.
- Redistribute unmodified releases with the original marks and notices.

## Not permitted

You may not:

- Use the marks as your product name, company name, domain, or app icon.
- Imply endorsement, partnership, or certification without written permission.
- Use the marks in a way that is confusing or misleading.
- Use a modified logo or combine the marks with another brand.
- Register a confusingly similar trademark or domain.

## Third-party marks

"Revizto" is a trademark of Revizto SA. Terrassay is independent and not affiliated with, endorsed by, or sponsored by Revizto. "GeoLibre" is a project of its respective authors; Terrassay credits it as the map engine. "DeepSeek" is used only to describe a development tool.

Do not use third-party logos in Terrassay branding, marketing, or app icons without permission.

## Forks

Forks are welcome under the licence. A fork must use a different name and logo if it is distributed, to avoid confusion with the official project. It may state that it is "based on Terrassay" if accurate.

## Reporting misuse

Contact the maintainers through the organisation profile. We prefer to resolve issues informally first.

This policy may be updated as the project grows; the current version lives in the repository.
