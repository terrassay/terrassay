## 1. The name

**Terrassay** is a coined compound:

- **Terra** — earth, ground, territory.
- **Assay** — to test, measure, and determine the quality of something.

Together: *to assay the ground and the physical assets on it.* That is the product: a workspace that tests project data against geographic reality and returns evidence, not guesses.

It fits the optional descriptor **“Physical Assets Intelligence platform”** without being literal or generic. It is short enough for a CLI (`terrassay`), distinctive enough to search for, and does not contain a vendor name.

**Tagline:** *Physical asset intelligence, grounded.*

**One-line description:** *Open-source site intelligence for construction: connect BIM data to geographic context, run spatial analyses, and ask grounded questions.*

---

## 2. Why this name

| Criterion | How Terrassay scores |
|---|---|
| Distinctive | Coined word; not a generic “GeoAI” or “SiteIQ” |
| Memorable | Three syllables; clear rhythm |
| Relevant | Earth + test/analysis; fits geospatial and construction |
| Extensible | Works for GIS, BIM, reality capture, and asset management |
| Open-source friendly | Neutral, no corporate suffix, easy GitHub handle |
| Searchable | No exact software match found in a preliminary search |
| Pronounceable | *teh-ruh-SAY*; spelling follows the sound |
| Domain potential | `.com`, `.org`, `.ai` showed no RDAP record; `.dev`/`.io` no DNS |

**Risks:**

- Some people may type “Terasay” or “Terrassary”. The double “s” is the only unusual part; the wordmark and docs should show it consistently.
- “Assay” is associated with mining and laboratories. That is acceptable: it signals measurement and evidence, not mining.
- “Therassay” is an unrelated laboratory platform with a different spelling and sector. It is not the same mark, but a formal trademark search is still required.

## 4. Trademark position

- A quick web search found no exact “Terrassay” software or construction product.
- “Therassay” is a different spelling in a different field; it is a watch item, not a blocker.
- “Terra” is a common prefix; the coined combination is the distinctive element.
- **A formal knock-out search (USPTO, EUIPO, Swiss IGE) and counsel review are still required before a commercial launch.** For the synthetic open-source testing phase, the risk is low, but the name is not “cleared” by this document.
- Do not use “Revizto”, “GeoLibre”, “DeepSeek”, or their logos in the name, domain, or icon.

## 7. Usage

- Always write **Terrassay** with a capital T and double “s”.
- CLI/package/repo: `terrassay`.
- Do not shorten to “Terra” in product copy (too generic and possibly confusing).
- Do not call it “Terrassay AI” in the product name; AI is a capability, not the identity.
- Use the descriptor after the name: *Terrassay — physical asset intelligence for the built environment.*
- The logo and wordmark are separate; see [TRADEMARKS.md](../TRADEMARKS.md).

---

## 8. If the name must change

Fallbacks that passed a quick availability screen or remain viable with a modifier:

1. **Terrassay** (current).
2. **Terrassay Labs** (only if a legal entity needs a suffix; the product stays Terrassay).
3. A new coined compound in the same family: *Terrassette*, *Terrassage*, *Terrassayer* — all weaker; only if a conflict appears.

Do not switch to a generic name under pressure. A rename after public launch is expensive; settle the name before the first public commit.
